📱 Module 1 — Introduction à TikTok Ads Manager
TikTok Ads Manager est la plateforme publicitaire self-serve de TikTok. Avec 1 milliard+ d'utilisateurs actifs mensuels et un algorithme de distribution puissant, TikTok offre un potentiel de reach exceptionnel — même pour les petits budgets.
🌐 Accès & création de compte
URL : ads.tiktok.com • Business Center — compte chapeau pour gérer plusieurs Ad Accounts et collaborateurs • Ad Account direct — accès simplifié pour un seul annonceur Conseil : créer le Business Center en premier, puis y rattacher l'Ad Account.
🧭 Les 5 sections du tableau de bord
• Tableau de bord — KPIs globaux sur la période choisie • Campagne — création, gestion et suivi • Actifs (Assets) — audiences, créatifs, Pixel • Rapports — exports personnalisés CSV/PDF • Outils — Pixel, Catalogue, Creative Center
📊 Métriques de la page d'accueil
Colonnes par défaut : Impressions · CPM · Clics · CPC · CTR · Conversions · CPA · Dépenses. Chaque métrique est cliquable pour trier. Période ajustable : Aujourd'hui / 7j / 30j / Personnalisée.
👤 Rôles & permissions
• Admin — accès total (création, modification, facturation) • Opérateur — gestion des campagnes, sans facturation • Analyste — lecture seule, rapports uniquement • Finance — paiements et facturation uniquement
💡 Conseil de démarrage
1. Installer le TikTok Pixel sur ton site (Module 8) 2. Vérifier que CompletePayment remonte correctement 3. Mettre au minimum 50 € de crédit publicitaire 4. Préparer au moins 3 vidéos en format 9:16 (Module 7)

🏗️ Module 2 — Structure des campagnes TikTok
TikTok Ads Manager est organisé en 3 niveaux hiérarchiques : Campagne → Groupe d'annonces → Annonce. Chaque niveau contrôle un aspect différent.
📐 Hiérarchie en 3 niveaux
Campagne (objectif + budget global) └─ Groupe d'annonces (audience + budget + enchère) └─ Annonce (vidéo + texte + CTA + URL)
🎯 Niveau 1 — Campagne
• 1 seul objectif par campagne (impossible à changer après création) • Option CBO : TikTok répartit le budget entre les Ad Groups selon les performances • Nommage recommandé : FR_Conversions_Sneakers_2025-03
👥 Niveau 2 — Groupe d'annonces
• Placement : automatique (recommandé) ou manuel • Budget : min 20 €/jour par Ad Group • Calendrier : dates fixées ou diffusion continue • Ciblage : démographie, intérêts, custom audiences • Enchère : Lowest Cost, Bid Cap, Cost Cap, ROAS min
🎬 Niveau 3 — Annonce
• Vidéo créative (upload ou bibliothèque) • Texte publicitaire : max 100 caractères • CTA : 28 options (Shop Now, Learn More, Sign Up, Download…) • URL de destination : landing page ou App Store
⚠️ Erreur fréquente à éviter
Modifier le ciblage ou le budget pendant la phase d'apprentissage (7-14j) relance l'algorithme à zéro. Observer uniquement pendant les 7 premiers jours.

🎯 Module 3 — Objectifs de campagne TikTok
L'objectif est le paramètre le plus important. Il détermine comment TikTok optimise la diffusion et quels utilisateurs voient tes annonces.
🗺️ Les 3 catégories
1. Notoriété → faire connaître la marque 2. Considération → générer intérêt et trafic 3. Conversion → déclencher une action (achat, inscription)
📣 Notoriété — Reach
• Maximise les impressions uniques • Facturation en CPM • Contrôle de fréquence (ex: max 2 impressions / 7 jours) • Idéal : lancement de marque, événements
🚦 Trafic (Traffic)
• Optimise vers les clics ou les vues de landing page • Préférer "Landing Page Views" : exclut les clics accidentels • Facturation en CPC ou CPM optimisé
📋 Génération de leads
• Formulaires natifs dans l'app TikTok — aucune redirection • Taux de complétion moyen : 15-20% vs 5-8% sur landing page externe • Leads exportables CSV ou connectables via Zapier/CRM
💰 Conversions — L'objectif ROI
• Requiert le TikTok Pixel installé • Événement cible recommandé : CompletePayment • Phase d'apprentissage : 50 conversions/semaine/Ad Group nécessaires • Facturation en oCPM (impressions, optimisation vers l'action)
📦 Ventes du catalogue
• Requiert un catalogue produits connecté • Ads dynamiques personnalisées par utilisateur • Idéal pour les boutiques avec 50+ produits

👥 Module 4 — Ciblage d'audience TikTok
TikTok recommande souvent un ciblage large pour laisser l'algorithme trouver les meilleurs utilisateurs. La clé : tester différentes combinaisons et laisser les données guider.
🌍 Ciblage démographique
• Localisation : pays, région, ville • Âge : 13-17 / 18-24 / 25-34 / 35-44 / 45-54 / 55+ • Genre : Homme / Femme / Tous • Langue de l'appareil : utile pour la diaspora francophone • Connexion : WiFi, 4G, 3G
🎮 Intérêts & comportements
• 200+ catégories : Beauté, Gaming, Finance, Voyage, Sport… • Comportements récents (30j) : a regardé, liké, suivi des créateurs dans [niche] • Max 3-5 intérêts cohérents par Ad Group
👤 Custom Audiences — 5 sources
• Fichier client : CSV emails/téléphones (~40-60% match rate) • Trafic web : visiteurs via Pixel (1-180 jours) • Engagement TikTok : viewers 25/50/75/100%, likes, partages • Activité app : utilisateurs de ton app mobile • Lead Gen : ayant soumis un formulaire Taille minimale recommandée : 1 000 personnes
🔮 Lookalike Audiences
• Source min 1 000 personnes (idéalement 10 000+) • Narrow 1% : très similaire, petite taille • Balanced 5% : compromis ← recommandé pour débuter • Broad 20% : large portée, moins similaire Meilleure source : acheteurs CompletePayment
🚫 Exclusions importantes
• Toujours exclure les acheteurs récents (30j) des campagnes acquisition • Exclure les audiences retargeting des campagnes prospection → Évite la cannibalisation et les dépenses inutiles

🎬 Module 5 — Formats publicitaires TikTok
TikTok propose plusieurs formats, du plus accessible au plus premium. Le In-Feed Ad est le point de départ pour 95% des annonceurs.
📲 In-Feed Ads — Le format standard
• Dans le fil "Pour toi", entre les vidéos organiques • Aspect natif — ressemble à du contenu organique • Durée : 5-60s (optimal : 15-30s) · Skipable après 6s • CTA cliquable vers URL ou App Store • Disponible pour tous les objectifs
✨ Spark Ads — Booster l'organique
• Booste un post organique existant (ton compte ou créateur) • Conserve les likes, commentaires, partages déjà existants • Recommandé pour débuter — l'algo favorise les Spark Ads • Autorisation valable 30 ou 365 jours
🔝 TopView — Impact maximal
• 1ère vidéo vue à l'ouverture de l'app, non-skipable 3s • Jusqu'à 60 secondes · Format premium • Idéal : lancements de produits, événements nationaux
💥 Brand Takeover
• Plein écran avant le fil "Pour toi" • 3-5s (image) ou jusqu'à 60s (vidéo) • 1 seul annonceur/jour/pays — exclusivité totale • Le format le plus impactant et le plus coûteux
📐 Spécifications techniques (In-Feed)
• Ratio : 9:16 vertical (obligatoire) • Résolution : 1080 × 1920 px minimum • Format : MP4 ou MOV • Taille max : 500 MB • Durée : 5-60s · Frame rate : max 60 fps • Zone safe : éviter 150px haut et 250px bas

💰 Module 6 — Budget & Stratégies d'enchères
Le budget et la stratégie d'enchère déterminent combien tu dépenses et comment TikTok achète les impressions. Un mauvais paramétrage peut gaspiller tout le budget en quelques heures.
💵 Budget journalier vs total
• Budget journalier : min 20 €/jour par Ad Group. L'algo peut dépenser jusqu'à 120% certains jours. • Budget total : réparti sur la durée. Idéal pour les promos à dates fixes. • CBO : budget au niveau campagne, TikTok répartit entre Ad Groups automatiquement.
🎯 Les 4 stratégies d'enchères
1. Lowest Cost (auto) — maximise les résultats sans contrainte. Idéal pour débuter. 2. Bid Cap — plafond d'enchère manuel. Contrôle total mais risque de sous-dépense. 3. Cost Cap — vise un CPA cible. Recommandé pour les conversions. 4. ROAS Minimum — optimise vers un retour sur dépenses. Requiert l'événement Purchase avec valeur.
⚙️ Phase d'apprentissage — Ne pas toucher !
Dure 7-14 jours ou jusqu'à 50 conversions/semaine/Ad Group. Pendant cette phase : aucune modification du ciblage, budget (±20% max), ni enchère. Observer uniquement — les résultats se stabilisent après.
💡 Règles budgétaires pratiques
• Budget test : 3× ton CPA cible en journalier Ex : CPA cible 20 € → 60 €/jour • Scaling : max +20-30% par modification, espacer de 48h • Budget minimum viable : 50 €/jour pour sortir de la phase d'apprentissage en 7 jours

🎨 Module 7 — Création de publicités performantes
Sur TikTok, le créatif est roi. L'authenticité et le format natif "TikTok style" surpassent systématiquement les productions léchées.
⏱️ La règle des 3 premières secondes
Si tu ne captes pas l'attention en 3 secondes, l'utilisateur swipe. Techniques : • Question choc : "Tu paies encore trop cher ta mutuelle ?" • Affirmation contre-intuitive : "Arrête d'économiser de l'argent." • Action visuelle forte : démonstration produit dès l'image 1 • Texte overlay : grande police, couleur contrastée, dès la 1ère frame
📋 Structure d'une pub e-commerce efficace
• 0-3s → Hook (accrocher l'attention) • 3-8s → Problème / douleur du client • 8-20s → Solution / produit • 20-25s → Preuve / témoignage / avant-après • 25-30s → CTA clair avec urgence
✍️ Copywriting (texte publicitaire)
• Limite affichée : 100 caractères • Inclure : bénéfice principal + urgence ou rareté • Exemples performants : — "🚚 Livraison offerte aujourd'hui — 2 000 clients satisfaits" — "⭐ -30% jusqu'à minuit • Stock limité"
📐 Spécifications vidéo
• Ratio : 9:16 vertical · Résolution : 1080×1920px • Format : MP4/MOV · Taille max : 500MB • Durée idéale : 15-30s · Frame rate : 30-60fps • Zone safe : éviter 150px haut + 250px bas (UI TikTok)
🧪 Stratégie créative
• Lancer 3-5 vidéos différentes par Ad Group • Fatigue créative moyenne : 7-14 jours • Renouveler dès que le CTR chute de 30%+ • UGC (style naturel, smartphone) surpasse souvent le studio • Budget UGC : 100-500€ via Billo, Insense, ou micro-créateurs

🔍 Module 8 — TikTok Pixel : Installation & Configuration
Le TikTok Pixel est un snippet JavaScript sur ton site qui envoie des données à TikTok. Sans Pixel, impossible d'optimiser les conversions ni de créer des audiences retargeting.
⚙️ Les 3 méthodes d'installation
1. Manuelle — copier-coller le code dans le <head> de chaque page. 2. Intégration partenaire — Shopify, WooCommerce, BigCommerce : 1 clic. Recommandé. 3. API Conversions (CAPI) — server-side, contourne les ad-blockers et restrictions iOS 14.5+. Plus précis.
📋 Événements standards à installer
• ViewContent — page produit visitée • AddToCart — produit ajouté au panier • InitiateCheckout — début du paiement • AddPaymentInfo — infos de paiement saisies • CompletePayment — achat confirmé ← le plus important • Lead · Subscribe · Search
🔧 Paramètres à transmettre
ttq.track("CompletePayment", { value: 49.99, currency: "EUR", content_id: "SKU123", content_type: "product", quantity: 1 }); Le paramètre value est obligatoire pour l'optimisation ROAS.
✅ Vérification & Diagnostics
• TikTok Pixel Helper : extension Chrome, vérifie les événements en temps réel • Test Events dans Ads Manager (Actifs → Événements → Test Events) • Match Rate : viser >60% (envoyer email/téléphone hashés)
⏳ Fenêtre d'attribution
• Par défaut : 7j après clic + 1j après vue • E-commerce standard : 7j clic / 0j vue • Produits à cycle long : 28j clic Configurable au niveau du Ad Group.

📊 Module 9 — Analyse & Optimisation des campagnes
Savoir lire les données est aussi important que créer des campagnes. L'optimisation est un processus continu : observer → analyser → décider → tester.
📈 KPIs essentiels et benchmarks
• CTR : moyen 1-3%, bon >3%, excellent >6% • CPM : moyen Europe 3-8 € • CPC : e-commerce 0,20-1,50 € • VCR (Video Completion Rate) : bon >30% • CPA : à comparer à ta marge produit • ROAS : objectif minimum 2-3x pour la rentabilité
🔍 Rapport personnalisé
Rapports → Rapport personnalisé → colonnes recommandées : Impressions · Reach · CPM · Clics · CTR · CPC · Dépenses · Conversions · CPA · ROAS • Filtrer par Ad Group → audiences rentables • Filtrer par Annonce → créatifs gagnants • Exporter CSV pour analyse Excel / Google Sheets
🧪 A/B Testing natif
• Tester 1 seule variable à la fois (ciblage, placement OU créatif) • Budget min : 50 €/variation/jour • Durée min : 7 jours • TikTok divise l'audience aléatoirement (pas de chevauchement) • Le gagnant est désigné avec un niveau de confiance statistique
⚡ Quand agir, quand attendre ?
✅ Augmenter le budget : CPA < objectif pendant 3 jours consécutifs ❌ Couper une annonce : CTR <0,5% après 2 000 impressions ❌ Couper un Ad Group : CPA >3× objectif après 5 000 impressions ♻️ Renouveler créatifs : fréquence >3 + CTR en baisse
🗓️ Cadence d'optimisation
• Jours 1-7 : observer uniquement, aucune modification • Semaine 2 : couper les sous-performants • Semaine 3+ : scaler les gagnants, tester de nouveaux créatifs Règle 3-3-3 : 3 Ad Groups × 3 annonces = 9 combinaisons → garder le top 3 après 7j

🚀 Module 10 — Stratégies avancées TikTok Ads
Une fois les bases maîtrisées, ces stratégies permettent de scaler tes campagnes, maximiser le ROAS et construire un funnel publicitaire complet.
🔄 Retargeting par niveau d'intention
Niveau 1 — Visiteurs du site (ViewContent, 30j) → Message découverte, mettre en avant les bénéfices Niveau 2 — Ajouts panier sans achat (AddToCart, 14j) → Offre incitative : livraison offerte, -10% Niveau 3 — Checkouts abandonnés (InitiateCheckout, 7j) → Urgence maximale : -20%, stock limité, garantie
📊 Optimisation ROAS (Value Optimization)
• Activer "Value Optimization" dans la stratégie d'enchère • Transmettre la valeur de commande avec CompletePayment • TikTok optimise vers les paniers les plus élevés • Requiert 50+ achats/semaine par Ad Group • Résultat : +15-30% sur le panier moyen selon les niches
⚡ Scaling horizontal vs vertical
Vertical : augmenter le budget de l'Ad Group actuel → Max +20-30% par modif · Espacer de 48h Horizontal : dupliquer l'Ad Group gagnant + nouvelle audience → Plus stable · Ne relance pas la phase d'apprentissage → Tester : autre pays, Lookalike 5% acheteurs, intérêts adjacents
🌐 Structure Full Funnel recommandée
Haut du funnel → Reach / TopView (notoriété) ↓ Milieu de funnel → Traffic / Video Views (cibler viewers 75%+ vidéo awareness) ↓ Bas du funnel → Conversions (retargeter visiteurs + AddToCart)
🤝 Creator Marketplace
• Plateforme officielle pour trouver des créateurs/influenceurs • Filtres : niche, localisation, taille d'audience, taux d'engagement • Combo gagnant : collaboration organique + Spark Ads • UGC de créateurs convertit en moyenne 3× mieux qu'une pub de marque
🎓 Ressources officielles
• TikTok Academy — certification gratuite "Advertising Fundamentals" • TikTok Creative Center — top ads par niche, pays, secteur • TikTok Business Help Center — documentation officielle La plateforme évolue vite → vérifier les nouveautés chaque mois
